Terminal

Konsole's terminal colours on tone 1, a tone below the window's main surface. The bright colours other than bright black reach 4.5:1. The normal colours are darker, so that they also carry light text as backgrounds, in mc and in status badges: about 3.7:1 either way. The greys are four steps: black, dark grey (bright black, 3.1:1), light grey (white) and white.

Editor

Kate's editor theme. The gutter sits a tone below the code with no line between them; the current line sits a tone above. A search for count puts the search highlight behind a match.

// Counts the files in a folder, skipping hidden ones. #include <QDir> #include "amber.h" static constexpr int kLimit = 4096; int countFiles(const QString &path) { QDir dir(path); int count = 0; for (const QFileInfo &info : dir.entryInfoList()) { if (info.fileName().startsWith(u'.')) continue; count += 1; } return std::min(count, kLimit); }
