Editor

Kate's editor theme. The gutter sits a tone below the code with no line between them; the current line sits a tone above.

// Counts the files in a folder, skipping hidden ones. #include <QDir> #include "amber.h" static constexpr int kLimit = 4096; int countFiles(const QString &path) { QDir dir(path); int count = 0; for (const QFileInfo &info : dir.entryInfoList()) { if (info.fileName().startsWith(u'.')) continue; count += 1; } return count > kLimit ? kLimit : count; }

Normal ANSI colours

How dark the eight normal colours are. A darker colour stands further from its bright one and carries light text when a program uses it as a background, but it is weaker as text on the terminal. No colour can do both at 4.5:1: the two meet near 3:1 as text and 4.4:1 under text.

Text selection

The text selection against the current line. More accent tells them apart better, but the comments in dim text fail on it beyond about 14 %.
